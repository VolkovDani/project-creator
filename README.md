# Project Creator

[English version](README.en.md)

Project Creator помогает находить противоречия в бизнес-требованиях одного проекта.
Создавать и редактировать проекты и требования можно без модели. Подключите
модель эмбеддингов для поиска по смыслу или модель генерации для попарного
сравнения. Project Creator покажет возможное противоречие и версии исходных
требований, чтобы вы могли решить, нужна ли правка.

Приложение рассчитано на одного пользователя и работает без облачных ключей.

## Быстрый старт

Для установки нужны нативный Linux x86_64, Python 3 и Docker Engine с Compose 2.20 или новее.

```bash
git clone --branch develop https://github.com/VolkovDani/project-creator.git
cd project-creator
./project-creator setup
```

Команда запустит PostgreSQL, бэкенд и веб-интерфейс. Откройте выведенный адрес (по умолчанию [127.0.0.1:3000](http://127.0.0.1:3000)), чтобы создать проекты и требования.

В шапке рядом с выбором языка включите переключатель «Тёмная тема». Браузер запомнит выбор для следующих посещений.

## Подключение моделей

[Models Configurator](https://github.com/VolkovDani/models-configurator/blob/develop/README.ru.md) — отдельное приложение для подключения локальных и внешних моделей. В его панели можно посмотреть настроенные профили, доступность провайдеров и какие локальные модели загружены в память. Один менеджер могут использовать несколько приложений на одном компьютере.

Запустите менеджер, скопируйте ID профиля для каждой нужной роли и укажите его в приватном `.env` Project Creator. Для генерации и эмбеддингов можно выбрать разных провайдеров. После настройки выполните `./project-creator setup --device remote --switch-device`. В этом же режиме можно подключиться напрямую к OpenAI-совместимому API. Во время переноса существующие установки CPU, GPU и NPU могут продолжать работать с сохранёнными настройками. [Пример подключения](docs/adr/012-standalone-model-manager.ru.md) · [Установка и выбор провайдеров](docs/setup-cli.md)

## Первая проверка

1. Создайте проект и добавьте два требования об одном правиле. Например, «Хранить журнал 30 дней» и «Удалять записи журнала через 7 дней».
2. Откройте раздел анализа, выберите «Все пары» и запустите проверку.
3. Откройте результат пары и сверьте объяснение с исходными текстами.

Чтобы остановить приложение с сохранением данных и моделей, выполните
`./project-creator down`. Для следующего запуска используйте `./project-creator up`.
