# Project Creator

[English version](README.en.md)

Project Creator помогает находить противоречия в бизнес-требованиях одного проекта.
Вы записываете требования, ищете их по смыслу и запускаете попарную проверку.
Локальная модель объясняет возможное противоречие и показывает версии обоих
требований. Вы решаете, нужна ли правка.

Приложение рассчитано на одного пользователя и работает без облачных ключей.

## Быстрый старт

Для запуска на CPU нужны нативный Linux x86_64, Python 3 и Docker Engine с
Compose 2.20 или новее. Перед первой установкой потребуется 24 ГиБ свободного
места. Для GPU и Intel NPU см. [выбор устройства и системные требования](docs/setup-cli.md).

```bash
git clone https://github.com/VolkovDani/project-creator.git
cd project-creator
./project-creator setup --device cpu
```

Команда скачает модели, запустит приложение и проверит индексацию и анализ на тестовых
данных. Откройте адрес, который она выведет (по умолчанию [127.0.0.1:3000](http://127.0.0.1:3000)).

## Первая проверка

1. Создайте проект и добавьте два требования об одном правиле. Например, «Хранить журнал 30 дней» и «Удалять записи журнала через 7 дней».
2. Откройте раздел анализа, выберите «Все пары» и запустите проверку.
3. Откройте результат пары и сверьте объяснение с исходными текстами.

Чтобы остановить приложение с сохранением данных и моделей, выполните
`./project-creator down`. Для следующего запуска используйте `./project-creator up`.
