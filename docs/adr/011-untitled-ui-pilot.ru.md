# ADR-011 — Стили Untitled UI для требований и анализа

[English version](011-untitled-ui-pilot.md)

## Решение

Используем бесплатные фирменные цвета и малую тень Untitled UI React как CSS-токены в существующих HTML-компонентах. Исходник закреплён на [fd321c4](https://github.com/untitleduico/react/blob/fd321c459f7c03173ffabf89bfe174827039643c/styles/theme.css). В адаптированной таблице стилей сохранён исходный [текст лицензии MIT](https://github.com/untitleduico/react/blob/fd321c459f7c03173ffabf89bfe174827039643c/LICENSE).

Пилот использует Next.js 16.4.6 и React 19.3.1. Нативные кнопки, подписи, списки выбора, радиокнопки, диалоги и раскрываемые группы уже поддерживают нужные взаимодействия. CSS сохраняет управление с клавиатуры и серверную разметку без дополнительных JavaScript-зависимостей. Платные ресурсы и переключение тёмной темы выходят за границы пилота.

## Применение

Добавляйте класс `ui-panel` к разделу требований или анализа. Таблица стилей задаёт семантические цвета, отступы, типографику элементов управления, границы, скругления, фокус и тени. Кнопки отправки форм получают основное оформление. Для запуска анализа используйте `primary-action`, для удаления — `destructive-action`. Сохраняйте нативное состояние disabled и признак невалидности поля. Используйте существующие Group и ResourceState для раскрытия групп, загрузки и повтора. Оповещения и сообщения о прогрессе сохраняют свои роли для скринридеров.

## Проверка и оставшиеся экраны

Браузерные примеры охватывают RU/EN, ошибки, загрузку, пустые результаты, отключённые элементы, клавиатурный фокус, раскрытые и свёрнутые группы, ход анализа и адаптивную вёрстку на ширинах 320, 390, 768, 960 и 1920 пикселей, включая CSS-масштаб 200%. Контраст текста основной кнопки с фоном составляет 6,62:1, индикатора фокуса на белом фоне — 4,96:1.

Следующие кандидаты на миграцию — список и форма создания проектов, обзор и навигация проекта, индексация и поиск. Каждую миграцию проверяем отдельно с сохранением работы с данными. В #46 зафиксированы исходные требования к доступности и компонентам.
