# Проверка устройств Intel Core Ultra 7 268V

[English version](intel-device-verification.md) · [Настройка NPU](intel-npu.md)

## Сравнение генерации на одинаковых весах, 9 ноября 2026 года

На коммите приложения `52a05514ca4964a82fd9b8a6439f52426690bafb` OpenVINO 2026.4.1 и GenAI 2026.4.1.0 запускали один экспорт Qwen2.5-7B-Instruct symmetric INT4 на CPU, Intel Arc GPU и Intel NPU. Ревизия исходника `a09a35458c702b33eeacc393d103063234e8bc28`, SHA256 манифеста `f36b13cbad8752f05d141eba6f817045986a615d13ffb5688fe417faeebca271`. Промпты трёх синтетических примеров TestOpenVINORealNPUSmoke содержали 923, 899 и 893 токена при лимите вывода 512 токенов. На каждом устройстве одни и те же примеры запускали дважды в одном процессе и один раз в новом процессе с сохранённым кешем компиляции.

| Показатель | CPU | Arc GPU | NPU |
| --- | ---: | ---: | ---: |
| Создание pipeline, пустой кеш компиляции (с) | 1,93 | 6,19 | 3,86 |
| Создание pipeline, повторное использование кеша (с) | 1,97 | 1,66 | 2,81 |
| Первая проверка коллизии с пустым кешем (с) | 39,23 | 11,36 | 9,23 |
| Медиана трёх проверок второго прохода (с) | 9,54 | 5,62 | 14,61 |
| Максимальный пиковый RSS процесса (GiB) | 8,28 | 1,23 | 6,43 |
| Совпадения с ожидаемым вердиктом за девять проверок | 6/9 | 7/9 | 9/9 |

Ошибки CPU и GPU относились к примеру с недостаточной информацией. Для NPU приведён отдельный подтверждающий прогон после восстановления рабочего процесса. RSS процесса не учитывает часть памяти драйвера и устройства. Измерение создания pipeline исключает импорт Python и проверку целостности модели. Кеш страниц ОС сохранялся. Время и вердикты относятся к этим входным данным, модели и среде выполнения.

## Автономная проверка эмбеддингов BGE-M3, 9 ноября 2026 года

BGE-M3 FP16 ревизии `5617a9f61b028005a4858fdac845db406aefb181` выдал нормализованные плотные векторы размерности 1024 на двух статических формах NPU. Токенизация, CLS pooling и L2-нормализация выполнялись на CPU. OpenVINO подтвердил выполнение на NPU, аппаратный счётчик занятости вырос. Динамическая форма не скомпилировалась. Окно 128 токенов в обоих проходах явно отклонило вход из 195 токенов. В окно 512 токенов поместились все 19 входов в обоих проходах.

| Показатель | 128 токенов | 512 токенов |
| --- | ---: | ---: |
| Валидные векторы | 36 | 38 |
| Медиана выполнения энкодера (мс) | 14,05 | 68,27 |
| Минимальный косинус с PyTorch FP32 | 0,99994995 | 0,99994995 |
| Минимальный косинус с Ollama F16 | 0,99999395 | 0,99997855 |
| Ожидаемый источник найден первым | 6/6 | 6/6 |

В конфигурации приложения эмбеддинги по-прежнему вычисляет Ollama. Эти фиксированные примеры подтверждают возможность работы со статическими окнами. Для смены провайдера эмбеддингов необходимы учёт профиля, обработка длинных входов и явная переиндексация.

Локальные материалы измерений сохранены в `logs/npu/benchmark22-20261109-130800/` и `logs/npu/bge-m3-20261109/`.

## Адаптеры приложения, 18 ноября 2026 года

На коммите `1b5b390e68d742de3c7f434e30cd10af27ac5814` Go-адаптеры получили три одинаковые синтетические пары в одном порядке дважды для каждого устройства. Ollama на CPU и Arc работала в отдельных локальных контейнерах версии 0.40.16 с одними весами Qwen2.5:7b GGUF Q4_K_M в режиме чтения (digest `845dbda0ea48ed749caafd9e6037047aa19acfcfd82e704d7ca97d631a0b697e`) и контекстом 32768. Действующий процесс OpenVINO NPU использовал указанный выше INT4-манифест. Прирост счётчика занятости NPU составил 42 455 285 мкс. API Ollama показал ноль байт модели на GPU в прогоне CPU и все 6 428 924 312 байт на GPU в прогоне Arc.

| Вызов Go-адаптера (с) | CPU | Arc | NPU |
| --- | ---: | ---: | ---: |
| Коллизия, первый / повторный | 60,41 / 32,98 | 22,34 / 17,91 | 6,52 / 6,04 |
| Совместимость, первый / повторный | 33,97 / 35,07 | 24,46 / 27,12 | 8,61 / 8,42 |
| Недостаточно информации, первый / повторный | 30,82 / 30,98 | 24,24 / 27,10 | 7,97 / 7,82 |

Все три адаптера вернули шесть ожидаемых вердиктов и ссылок на исходники. Для Ollama запускались новые процессы. Рабочий процесс NPU уже был прогрет. Измерено полное время вызова адаптера с проверками и допустимыми повторами. Между адаптерами различаются веса, промпты и настройки среды. Таблица не позволяет выделить ускорение от аппаратуры. Журналы находятся в `logs/npu/issue22-20261118/`.
