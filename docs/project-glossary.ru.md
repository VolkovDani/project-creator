# Словарь проекта

[English version](project-glossary.md)

Откройте **Словарь проекта**, чтобы создавать, искать, изменять и удалять подтверждённые понятия текущего проекта. У понятия есть каноническое название, определение, контекст применения и варианты (сокращения, синонимы и варианты написания). Выделите текст в раскрытом оригинале требования, чтобы создать запись или связать выделение с существующим понятием. Редактор сохраняет исходное требование и его версию. Версия понятия позволяет выявлять конфликты редактирования.

Словарь проверяет требования и ищет полное название с сокращением из заглавных букв в скобках. Начальные буквы последних слов должны совпадать с сокращением по порядку. Выберите кандидата, проверьте текст и подтвердите сохранение. Понятия и предложения загружаются независимо по 20 найденных записей, с бесконечной прокруткой или по страницам. Предложение само по себе не меняет словарь.

В оригинале требования буквами слова считаются Unicode-буквы, комбинируемые знаки, цифры и подчёркивания. Предпочтение отдаётся наиболее длинному целому совпадению. Наведите указатель на подсвеченный вариант или переведите на него фокус, чтобы увидеть определения рядом с текстом. Нажатие закрепляет подсказку и открывает доступ к редактированию выбранного значения. Escape закрывает подсказку. Копирование оригинала сохраняет его текст.

Генератор выжимок получает найденные подтверждённые определения с ID и ревизиями понятий в пределах примерно 3 КиБ JSON. Для неоднозначных обозначений передаётся признак неоднозначности. Изменение словаря сбрасывает актуальность затронутых выжимок текущей версии и исключает запись результата уже устаревшей генерации. Настроенный обработчик пересчитывает выжимки асинхронно. Отмена сохраняет силу. Исходный текст, версия требования и индекс эмбеддингов сохраняются.

Нажмите **Где упоминается** у понятия, чтобы увидеть актуальные требования
проекта с его названием или вариантами по правилам подсветки оригинала.
Выберите требование для перехода к карточке. Каждое требование показано один раз.

В требованиях, поиске, индексации и анализе пар словарное окно доступно для
ручного ввода и выделенного текста. Для источника сохраняется показанная версия
требования. Выделение в выжимке или пояснении модели заполняет только название.
