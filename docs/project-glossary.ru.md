# Словарь проекта

[English version](project-glossary.md)

Откройте **Словарь проекта**, чтобы создавать, искать, изменять и удалять подтверждённые понятия текущего проекта. У понятия есть каноническое название, определение, контекст применения и варианты (сокращения, синонимы и варианты написания). Выделите текст в раскрытом оригинале требования, чтобы создать запись или связать выделение с существующим понятием. Редактор сохраняет исходное требование и его версию. Версия понятия позволяет выявлять конфликты редактирования.

Словарь проверяет требования и ищет полное название с сокращением из заглавных букв в скобках. Начальные буквы последних слов должны совпадать с сокращением по порядку. Выберите кандидата, проверьте текст и подтвердите сохранение. Понятия и предложения загружаются независимо по 20 найденных записей, с бесконечной прокруткой или по страницам. Предложение само по себе не меняет словарь.

Словарь также предлагает отдельные слова из 2–8 заглавных букв, например ГП, если такого названия или варианта ещё нет в словаре проекта. Для каждого требования показана своя цитата с контекстом до 60 символов с каждой стороны от выделенного сокращения. В списке кандидатов и в редакторе крайние буквы цитаты постепенно бледнеют с той стороны, где исходный текст продолжается. Нажмите **Открыть в тексте**, чтобы увидеть выделенное упоминание в оригинале. Если требование изменилось, откроется текущая версия с уведомлением. Выберите кандидата, чтобы ввести полное название или привязать сокращение к существующему понятию. Поиск существующего понятия доступен и при выделении текста в выжимке.

В редакторе кандидата нажмите **Сгенерировать определение**, чтобы запросить черновик у локальной модели, настроенной для выжимок требований. В отрывке подсвечено выбранное сокращение. Модель получает исходное требование целиком и может использовать описание роли из другого предложения, даже если полное название неизвестно. Если модель привела цитату в поддержку определения, сервер проверяет, что в неё входит выбранное вхождение сокращения, с учётом различий в пробелах. Если цитаты нет или она указывает на другой фрагмент, модель получает ещё одну попытку описать употребление термина по строке, где он встречается. Это помогает избежать подмены смысла соседним пунктом списка. Такой черновик редактор помечает как **Гипотеза ИИ**. Если после двух попыток описания нет, редактор сообщает о нехватке контекста.

Нажмите **Скопировать**, чтобы перенести в буфер только текст черновика. Если браузер запретил доступ к буферу, редактор выделит текст для ручного копирования. Нажмите **Применить**, чтобы перенести черновик в поле определения, затем отредактируйте и сохраните его, когда будете готовы. Повторная генерация сохраняет введённый вами текст определения. При изменении версии требования заново откройте кандидата из обновлённого списка. Если локальная Ollama недоступна или требование целиком превышает лимит входных данных модели, определение можно ввести вручную.

В оригинале требования буквами слова считаются Unicode-буквы, комбинируемые знаки, цифры и подчёркивания. Предпочтение отдаётся наиболее длинному целому совпадению. Наведите указатель на подсвеченный вариант или переведите на него фокус, чтобы увидеть определения рядом с текстом. Нажатие закрепляет подсказку и открывает доступ к редактированию выбранного значения. Escape закрывает подсказку. Копирование оригинала сохраняет его текст.

Генератор выжимок получает найденные подтверждённые определения с ID и ревизиями понятий в пределах примерно 3 КиБ JSON. Для неоднозначных обозначений передаётся признак неоднозначности. Изменение словаря сбрасывает актуальность затронутых выжимок текущей версии и исключает запись результата уже устаревшей генерации. Настроенный обработчик пересчитывает выжимки асинхронно. Отмена сохраняет силу. Исходный текст, версия требования и индекс эмбеддингов сохраняются.

Нажмите **Где упоминается** у понятия, чтобы увидеть актуальные требования
проекта с его названием или вариантами по правилам подсветки оригинала.
Выберите требование для перехода к карточке. Каждое требование показано один раз.

В требованиях, поиске, индексации и анализе пар словарное окно открывается из
выделенного текста. Для ручного ввода нажмите **Новое понятие** на странице словаря проекта. Для источника сохраняется показанная версия
требования. Выделение в выжимке или пояснении модели заполняет только название.

В анализе пар в сохранённом пояснении модели подсвечиваются названия и варианты из текущего словаря проекта. Наведите указатель на совпадение или переведите на него фокус, чтобы прочитать определение. После правки словаря подсветка обновляется и в прежних результатах без повторного анализа. Исходные требования в каждой паре показываются в версии, сохранённой при анализе.

В готовом резюме термины текущего словаря проекта выделяются прямо в строке фоном и точечным подчёркиванием, как в оригинале. Подсветка работает и для ранее сохранённых резюме без повторной генерации.

Для подсветки браузер получает границы совпадений и идентификаторы понятий. При показе текста он загружает недостающие определения одним или несколькими пакетами и использует их повторно в других текстах того же проекта. Для свёрнутого оригинала загрузка начинается при раскрытии. Изменения словаря обновляют совпадения и определения в отображаемых текстах.
