# Source + Compose v0.1.0 (первый prerelease MVP)

English version: [release-notes-v0.1.0.md](release-notes-v0.1.0.md).

Выпуск содержит локальный однопользовательский MVP Project Creator. Он
предназначен для локальной работы одного пользователя и не предоставляет
разграничение доступа для нескольких пользователей. Это первый prerelease MVP.
Аппаратные отчёты ниже относятся только к указанным устройствам и профилям; они
не подтверждают широкую совместимость или качество на оборудовании.

## Состав

- Карточки проектов и бизнес-требования в PostgreSQL + pgvector.
- Локальные embeddings и явный семантический поиск в пределах проекта.
- Явный анализ пар локальной моделью с версиями источников, отменой, повторами,
  восстановлением, прогрессом и кешированием результатов.
- Русские выжимки сохраняют отдельные технические названия из оригинала, например
  Excel, API и PDF, не разрешая произвольный английский текст (issue #136).
- Развёртывание Docker Compose: CPU по умолчанию; дополнительные варианты Intel,
  NVIDIA, AMD ROCm и AMD Vulkan зависят от оборудования и драйверов хоста.

## Свидетельства на историческом baseline

Отчёт от указанной даты и описанные проверки относятся к исходному baseline
`5fb98a8d29c4161c0904eb43d103442853ddd053`, а не к финальному SHA публикации.
Это исторические свидетельства, они не подтверждают финального кандидата.

- Детерминированные Go/frontend/Playwright и контейнерные проверки описаны в CI
  и отчётах приёмки; они не подтверждают качество модели на реальном
  оборудовании.
- Один реальный `TestRealAnalysisSmoke` завершился успешно: 2/2 случая (известный
  конфликт и совместимая пара). Использованы Qwen2.5:7b, digest
  `845dbda0ea48ed749caafd9e6037047aa19acfcfd82e704d7ca97d631a0b697e`, тогдашний
  Ollama container и временный loopback relay. Лог:
  `logs/release-v0.1.0/real-analysis-loopback.log` (локальный, не коммитится).
  Это проверка одного профиля анализа на одном хосте.
- **Известное ограничение, issue открыта:** отдельный smoke качества выжимок на
  реальной Qwen2.5:7b получил 3/5 за 135,14 с: в двух русских лексических
  сценариях ответ был на английском. См. [issue #108](https://github.com/VolkovDani/project-creator/issues/108).
  Прогон на 90 идентификаторах завершился за 98 секунд без timeout. Это
  зафиксированное ограничение, а не приёмка качества выжимок.
- Изолированная проверка `pg_dump`/восстановления PostgreSQL прошла; сохранены
  все 34 SQL-команды вставки данных. Это подтверждает только round-trip
  резервной копии БД, но не обновление приложения.
- Точные baseline, команды, результаты и открытые проверки приведены в
  [отчёте от 17 ноября 2026 года](release-verification-2026-11-17.md).

## Ограничения

- Аппаратное покрытие и проверка профилей неполные. Один smoke не подтверждает
  широкую совместимость или качество модели. Дополнительные отчёты можно собрать
  после публикации; точно перечисляйте проверенные и непроверенные сочетания.
- Полная чистая установка с реальной моделью и обновление/миграция приложения
  не приняты. Контейнерный smoke использовал заглушки; отдельная проверка
  PostgreSQL dump/restore подтверждает только round-trip базы данных. Перед
  публикацией release workflow должен пройти на точном source SHA.
- GPU/NPU-конфигурации требуют совместимых устройств, драйверов и runtime;
  возможности зависят от конкретного устройства. См. аппаратную матрицу README.
- Поиск и подготовка пар могут быть дорогими на больших проектах; общий
  поддерживаемый верхний предел размера не установлен.
- Исправления документации и установки можно выпускать в patch-релизах.
