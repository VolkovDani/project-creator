# Предрелизная проверка — 17 ноября 2026

[English version](release-verification-2026-11-17.en.md)

Исходный код приложения: `5fb98a8d29c4161c0904eb43d103442853ddd053`.
Изменения процесса выпуска проверяются отдельно в PR задачи #106.
Этот отчёт не является приёмкой финального релизного SHA.

## Подтверждённые результаты

- Frontend: format:check, 68 тестов, typecheck и production build прошли.
- Playwright UX: 96 прошли, 6 пропущены; E2E: 54 прошли.
- Изолированный Compose smoke прошёл, включая рестарт PostgreSQL/backend.
- `pg_dump -Fc` и восстановление через `pg_restore --exit-on-error` прошли
  на отдельной БД после E2E; дампы данных совпали (34 INSERT-записи).
  Это проверка восстановления БД, а не полного обновления приложения.

- `python3 -m unittest discover -s runtime/setup -v`: 87 тестов прошли.
- `python3 -m unittest discover -s runtime/npu -v`: 36 тестов прошли.
- `go test -p 1 ./...` с изолированной PostgreSQL и `go vet ./...` прошли.
- `TestRealAnalysisSmoke`: два сценария прошли — противоречие (28,02 с)
  и совместимость (26,74 с), всего 54,76 с.
- `TestSummaryQualitySmoke`: 3 из 5 сценариев прошли за 135,14 с.
  Оба английских сценария прошли. В двух русских сценариях модель выдала
  английские выжимки, поэтому лексическая проверка русских формулировок упала.
  Это не доказывает потерю всех перечисленных фактов, но требует проверки
  языкового поведения и не позволяет объявить quality smoke успешным.
- Сценарий с 90 идентификаторами прошёл за 98,03 с без таймаута;
  выжимка сохранила идентификаторы и осталась непригодной по размеру для Laya.

Реальные тесты использовали установленную локальную `qwen2.5:7b`, digest
`sha256:845dbda0ea48ed749caafd9e6037047aa19acfcfd82e704d7ca97d631a0b697e`.
Подключение к Ollama выполнялось через временный loopback-прокси;
прокси завершены после тестов. Рабочий Compose не перезапускался.

Полные локальные логи находятся в исключённом из Git каталоге
`logs/release-v0.1.0/`. Они не входят в исходники релиза.

## Незавершённая приёмка

- Полный CI и container smoke на финальном SHA.
- Чистая установка по опубликованным инструкциям и проверка обновления БД.
- Реальный браузерный reconnect/reset и проверка пользовательских сценариев.
- Документированная конфигурация оборудования, память и границы масштаба.
- Разбор языкового результата quality smoke и явное решение о релизном профиле.

До завершения этих пунктов тег и публикация v0.1.0 не подтверждены.

## Очистка

В отслеживаемых файлах не найдены логи, временные файлы, screenshots,
Playwright reports или содержимое локальных worktree. Исключения Git и Docker
уже защищают логи, `.env`, веса `.npu/` и резервные копии.
Незавершённые ветки и чужие worktree сохраняются; их наличие не является мусором.

Созданные для проверок Compose-ресурсы и отдельный контейнер тестовой БД удалены.
Временные дампы удалены; диагностические логи сохранены для разбора.
